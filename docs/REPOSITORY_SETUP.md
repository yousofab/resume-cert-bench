# GitHub repository setup

Target: `yousofab/resume-cert-bench`. The initial contents are a research proposal and a reproducible witness.

| Setting | Intended value |
| --- | --- |
| Default branch | `main` |
| Initial visibility | Private for review |
| Description | Budgeted evidence for resuming agent workflows after external state changes. |
| Topics | `agentic-ai`, `workflow-automation`, `reproducible-research`, `formal-verification`, `benchmark` |
| Collaboration | Issues enabled; wiki, projects, and discussions off |
| Pull requests | Squash merge; delete merged head branches |
| GitHub Actions | Reproducibility job on pushes to main and pull requests; read-only content permission |
| Branch rule if supported by the repository plan | Require a pull request and passing Reproducibility check; prevent force pushes and branch deletion |

A scope-specific code and data license can be selected before public release. The two institutional marks are separate from code and data licensing. No new collaborators or organization permissions are required for the initial setup.
